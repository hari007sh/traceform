## What is Traceform?

Traceform is an open-source AI agent production platform that replaces 5-6 separate tools with one unified system. It provides everything you need to build, monitor, and operate AI agents reliably in production.

### Six Modules

- **Shield** -- Self-healing SDK that auto-fixes loops, hallucinations, cost overruns, and timeouts. Thread-safe healing engine with bounded retries and atexit shutdown hooks. This is the unique differentiator no other platform offers.
- **Trace** -- Observability with a split-pane session explorer, distributed tracing, failure pattern detection, and alerting. Features infinite scroll, keyboard navigation, virtual scrolling for span trees, and a D3 Gantt chart for session replay.
- **Test** -- Evaluation framework with 15+ evaluators, CI/CD quality gates (`traceform test run --ci --threshold 95 --format junit`), and regression testing.
- **Guard** -- Guardrails for PII detection, toxicity filtering, prompt injection detection, and custom policies. All guard types execute in parallel with short-circuit on block.
- **Route** -- Gateway with model routing, provider failover, circuit breakers, singleflight caching, and streaming with context cancellation.
- **Cost** -- Cost intelligence with per-outcome tracking, budget enforcement with metering, query caching, and CSV/JSON data export.

### Key Differentiators

- **Self-healing agents**: Shield automatically detects and fixes failures at runtime -- no other platform does this.
- **Unified platform**: Six modules in one system instead of stitching together Langfuse, DeepEval, Portkey, Guardrails AI, and custom code.
- **Open-source**: Self-host for free, or use the managed cloud offering with team and enterprise tiers.
- **Enterprise-ready**: RBAC (owner/admin/viewer), SSO (SAML and OIDC with JIT provisioning), audit logging, GDPR deletion, API key rotation, and plan-gated features.

## Quick Start

Get up and running in under 10 minutes:

```bash
git clone https://github.com/traceform/traceform.git
cd traceform
docker compose up -d
make migrate && make seed
make dev                        # API server on :8080
cd web && PORT=3001 npm run dev # Dashboard on :3001
```

> **Note**: Port 3000 may be taken by other applications. Use `PORT=3001` for the dashboard.

```python
pip install traceform

import traceform

traceform.init(api_key="tf_sk_...", endpoint="http://localhost:8080")

with traceform.session(agent_name="my-agent") as session:
    with session.span("llm-call", span_type="llm_call") as span:
        span.set_input({"prompt": "Hello"})
        span.set_output("Hi there!")
        span.set_tokens(50, 20)
```

## Architecture

```
SDK (Python / TypeScript)
    |
    v
API Server (Go, :8080)  -->  NATS  -->  Workers  -->  ClickHouse
    |                                                    (time-series)
    v
PostgreSQL (config, users, RBAC, SSO, audit logs)
    |
Redis (rate limiting, query cache, JWT blacklist, sessions)
    |
Gateway Proxy (Go, :8090)  -->  OpenAI / Anthropic / Google / ...
    |
Dashboard (Next.js, :3001)
    |
Docs (Fumadocs, :3002)
```
